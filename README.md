# Mac Admins Toolkit

A collection of practical **macOS administration scripts, MDM utilities, Jamf Pro tools, Extension Attributes, and automation** for Apple device management.

The repository includes both **MDM-agnostic tools** and utilities designed for specific platforms such as Jamf Pro.

## Compatibility

Scripts are designed with current enterprise macOS environments in mind, including:

- macOS 27
- macOS 26
- macOS 15

Compatibility and dependencies may vary by tool. Check the documentation and comments included with each script before deployment.

## Security

Never store credentials, API secrets, tokens, private keys, or organisation-specific sensitive information in scripts committed to the repository.

Always review and test scripts before deploying them in a production environment.
